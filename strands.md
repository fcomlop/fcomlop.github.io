## Strands

<br>

### How to play

<div class="imageflex">
<div>
Strands is part of the <a href="https://www.nytimes.com/games/strands"> New York Times games suite</a>. To play, you need to find the secret words in a grid of letters. Each grid follows a theme from a paper. I recommend reading the papers for clues.  
<br><br>
I create the grids using <a href="https://strandstudio.thegoodboi.net/make">Strandstudio maker</a>, but the implementation of the game is my own. Feel free to use it in your website.
